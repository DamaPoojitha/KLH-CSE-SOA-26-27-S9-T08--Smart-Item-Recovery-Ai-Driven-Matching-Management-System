## Abstract
In educational institutions, corporate campuses, and large organizations, managing lost and found belongings manually via traditional registries is inefficient, time-consuming, and error-prone. The **Smart Item Recovery Portal** addresses this by providing a secure, scalable, and intelligent lost and found management platform powered by a **Microservices Architecture** built with **Spring Boot** and **Spring Cloud**.

The core innovation of the system is its **AI Matching Service**, which automates lost and found item matching. By employing **Natural Language Processing (NLP)** techniques—specifically **TF-IDF (Term Frequency-Inverse Document Frequency)** vectorization and **Cosine Similarity**—the system calculates similarity scores between lost and found item descriptions to present real-time, highly relevant potential matches to users.
